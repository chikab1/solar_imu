# Solar IMU 项目状态

更新时间：2026-08-02

## 项目目标

面向室外路牌倾倒、撞击和异常姿态监测，形成可量产、低功耗、可诊断、断网不丢关键事件的STM32G031 + LSM6DS3TR-C + ML307C-GC-CN终端。

## 当前基线

| 模块 | 当前状态 | 说明 |
|---|---|---|
| Stop1低功耗 | 已实现，持续实机验证 | IMU、RTC和维护串口可唤醒 |
| IMU Wake-Up/6D | 已实现并通过阶段性实测 | 共用锁存INT1，MCU进行3秒软件复核 |
| 安装零度 | 已实现 | 支持Z+/Z-/X+/X-/Y+/Y- |
| 4G/MQTT上报 | 已实现 | 测试环境仍为1883和共享账号 |
| MQTT可靠性 | 已实现基础链路 | QoS 1、PUBACK、event_id去重依据 |
| 失败事件队列 | 已实现 | 片内Flash最多保存3条 |
| USART2维护协议 | 已实现 | 二进制帧、CRC、Sequence、错误码和Stop1唤醒 |
| 串口文档 | 已完成 | 见docs/USART2串口通信指令手册.md |
| OTA | 暂不实施 | 64 KB Flash不足，以USART2/SWD升级为主 |

## 当前阶段

工程样机功能稳定与量产前风险收敛。

当前优先级：

1. 保持IMU Wake-Up、6D和安装角度长期稳定，收集误报/漏报数据。
2. 测量Stop1、采样、4G注册和MQTT发布各阶段真实功耗。
3. 验证低压、弱信号、断网、服务器不可达和反复复位等极端路径。
4. 量产前完成MQTT TLS和独立设备凭据。
5. 建立版本、生产烧录、序列号/UID/IMEI/ICCID映射和出厂测试流程。
