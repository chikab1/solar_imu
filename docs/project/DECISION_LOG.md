# 项目决策记录

## DEC-20260802-001 需求沟通与项目管理机制

日期：2026-08-02  
状态：生效

### 背景

用户希望只需提出模糊需求，由Codex承担项目经理职责，组织澄清、技术分析、实施、测试和进度管理，并把确认结论持久化。

### 决策

- 当前主线程作为项目经理统一入口。
- 每个需要澄清或实施的需求建立独立REQ文件。
- 需求明确后自动写入确认内容、验收标准和范围。
- 实施、验证和发布状态同步到PROJECT_STATUS.md。
- 架构级选择追加到本决策日志。
- 可拆分独立分析任务，但需要用户确认的选择由项目经理统一沟通。

### 影响

后续即使更换对话或开发者，也能从仓库恢复需求背景、已做决定、当前进度和未完成事项。

## DEC-20260802-002 上位机技术路线与发布方式

日期：2026-08-02  
状态：生效

### 决策

- 上位机仅面向Windows 10/11 x64。
- 使用Python、PySide6、pyserial和PyInstaller。
- 最终用户版本采用免安装单文件EXE，目标电脑无需安装Python。
- 同时生成便携目录版用于现场排错；不制作需要管理员权限的安装器。
- 实时角度默认100 ms，通过GET_ANGLE一次读取Pitch和Roll。
- V1显示数值、趋势和简化3D姿态。
- V1不修改固件协议，六轴功能仅预留页面。

### 原因

免安装版本适合现场维护电脑和小批量分发；PySide6能实现现代多页面界面。目录版启动和杀毒兼容通常优于单文件版，可作为现场兜底。现有协议已经覆盖V1主要功能，暂不扩展固件可降低联调风险。
